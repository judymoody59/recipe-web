### 용어

| 표기 | 뜻 |
|---|---|
| 레시피 (recipe) | 사용자가 올리는 요리법. 도메인 이름 `recipe` |
| 댓글 (comment) | 레시피에 다는 글. 도메인 이름 `comment` |
| 인증 (auth) | 로그인과 사용자 식별. 도메인 이름 `auth` |
| 업로드 (upload) | 레시피 작성 시 파일(이미지 등)을 올리는 기능. 도메인 이름 `upload` |
| 도메인 모듈 | `src/domain/<도메인 이름>/` 한 디렉터리 |

### 폐기된 별칭

폐기된 별칭 없음
