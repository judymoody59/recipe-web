## T2 · feat: 더미 계정과 로그인·회원가입 함수 추가

### 상위 Requirement

- relates to #11

### 작업 내용

API 를 대신하는 더미 계정 저장과 로그인·회원가입 함수를 만든다. 명세 5-3, 6-7, 7-1, 7-2.
필드 이름·타입·응답 형태는 `docs/api/auth.md`, 오류 틀은 `docs/api/README.md` 와 같다.

- `src/lib/api-error.ts` — 오류 틀 `{ code, message }` 를 담는 오류 클래스. 모든 도메인의 더미
  함수가 실패를 이 오류로 알린다
- `src/domain/auth/types/` — `User`, `Role`, 로그인 요청·응답, 회원가입 요청.
  `User.preferredCategory` 는 `src/domain/recipe/types` 의 `Category` 를 쓴다
- `src/domain/auth/api/`
  - 계정 저장 — 모듈 변수. 시드 계정 하나(명세 7-1 의 표)로 시작한다. 계정 하나는 `User` 에
    비밀번호를 더한 것이다
  - `login({ loginId, password })` — 성공하면 `{ accessToken, user }`, 실패하면
    `INVALID_CREDENTIALS`. 아이디가 없는 것과 비밀번호가 틀린 것을 구분하지 않는다
  - `signUp({ loginId, password, nickname, email, profileImageUrl, preferredCategory })` —
    성공하면 만들어진 `User`, 같은 `loginId` 가 있으면 `DUPLICATED_LOGIN_ID`
  - 계정 저장을 시드 상태로 되돌리는 함수 — 테스트가 쓴다
- `src/domain/auth/hooks/` — `login`·`signUp` 을 감싼 TanStack Query mutation 훅 둘

지킬 것

- 입력값을 다듬지 않고 그대로 견준다. 앞뒤 공백을 떼지 않는다
- 어떤 응답에도 비밀번호를 담지 않는다
- `signUp` 이 만드는 `User` — `userId` 는 들어 있는 계정의 가장 큰 `userId` + 1, `role` 은 `USER`,
  `createdAt`·`updatedAt` 은 같은 값이고 `2024-02-09T09:46:44Z` 형태(UTC, 초 단위)다
- `profileImageUrl`·`preferredCategory` 는 값이 없어도 필드를 빼지 않고 `null` 로 둔다
- 브라우저 저장소와 쿠키에 아무것도 쓰지 않는다

### 완료 조건

- [ ] 시드 계정(`recipe01` / `pass1234`)으로 `login` 이 성공하고, 그 밖의 조합은 `INVALID_CREDENTIALS` 로 실패한다
- [ ] `signUp` 으로 만든 계정으로 같은 세션에서 `login` 이 성공한다
- [ ] 이미 있는 `loginId` 로 `signUp` 하면 `DUPLICATED_LOGIN_ID` 로 실패하고 계정이 늘지 않는다
- [ ] 로그인·회원가입 응답에 비밀번호가 없다
- [ ] `src/lib/api-error.ts` 가 `src/domain`·`src/app` 을 import 하지 않는다
- [ ] 아래 단위 테스트가 통과한다
- [ ] `script/run-lint-test.sh` 가 통과한다

## T3 · feat: 회원가입 입력 검증 규칙 추가

### 상위 Requirement

- relates to #11

### 작업 내용

회원가입 1·2단계의 검증 규칙과 화면 문구를 만든다. 명세 6-6, 6-7.

- `src/domain/auth/utils/` 에 둔다. 규칙은 zod 스키마로 쓴다
- 1단계 검증 — 아이디·비밀번호·비밀번호 확인을 받아 **처음 걸린 규칙의 문구 하나** 또는 통과를 돌려준다
- 2단계 검증 — 닉네임·이메일을 받아 같은 방식으로 돌려준다
- 규칙의 순서와 문구는 명세 6-6 의 표와 같다
- 이메일 형식 — `@` 가 하나이고, 그 앞과 뒤가 비어 있지 않고, 뒤쪽에 `.` 이 있으며, 공백이 없다
- 아이디 중복 문구 "이미 사용 중인 아이디입니다." 를 같은 자리에 상수로 둔다
- 입력값을 다듬지 않고 그대로 검사한다. 최대 길이와 허용 문자를 검사하지 않는다
- 프로필 사진과 선호 카테고리를 검사하지 않는다

### 완료 조건

- [ ] 1단계 검증이 아이디 4자 이상 → 비밀번호 8자 이상 → 비밀번호 확인 일치 순서로 검사한다

- [ ] 여러 규칙에 걸려도 처음 걸린 규칙의 문구 하나만 돌려준다
